# 算命学鑑定 by SATSUKI

`index.html` をブラウザで開くと動く、ローカル完結の算命学チャート計算アプリです。

## できること

- 生年月日、大運計算の性別区分から陰占を算出
- 陽占の人体星図、十大主星の鑑定、十二大従星の鑑定を表示
- 十二大従星を人生の山グラフで表示
- 大運、年運、月運を表示
- 五行バランスを簡易表示
- 今月の過ごし方を長文の総合鑑定として表示

## 採用している計算

- 年柱は立春で切り替えます。
- 月柱は二十四節気の「節」で切り替える節月方式です。
- 日柱は 2000-01-01 = 戊午日を基準に60干支を進めます。
- 蔵干は節入りからの経過日数で二十八元表から選びます。
- 大運の順逆は「陽年男性式・陰年女性式は順行、陰年男性式・陽年女性式は逆行」です。
- 起運年齢は、順行なら次の節、逆行なら前の節までの日数を3で割って算出します。

## 注意

二十四節気はアプリ内の天文近似式で算出しています。出生地、23時以降の日替わり、節入り時刻の厳密値、蔵干の取り方は流派差が出やすい部分です。商用・本鑑定用途では、採用する流派の万年暦や節入りデータで照合してください。
